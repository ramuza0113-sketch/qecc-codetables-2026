\begin{abstract}
We present a unified algebraic, geometric, and GPU-accelerated framework for constructing pure $q$-ary quantum error-correcting stabilizer codes across prime and prime-power alphabets $q \in \{2, 3, 4, 5, 7, 8\}$. Combining four complementary constructions---(i)~comb-free multi-eigenmode Vandermonde bordered $\lambda$-constacyclic Hermitian codes diagonalized via the discrete Fourier transform over $\mathbb{F}_{q^2}$, (ii)~equivariant $\mathbb{F}_q$-linear symplectic stabilizer codes accommodating both odd and even stabilizer ranks $r_S = n - k$, (iii)~symmetry-free navigation of the Hermitian isotropic Grassmannian via Dieudonn\'e--Witt rank-$1$ unitary Householder reflections, and (iv)~Frobenius-conjugated $2$-block and $3$-block non-singular-by-columns (NSC) quasi-unitary matrix-product codes over projective generalized Reed--Solomon components---we construct \textbf{397 explicit pure parent stabilizer codes} spanning block lengths $11 \le n \le 100$ and pure minimum distances $4 \le d \le 16$ (including 116 direct $\Delta d = +2$ leaps and 20 odd-$r_S$ symplectic codes). Under strictly pure secondary propagation ($\mathrm{PureSubcode}$, $\mathrm{Puncture}$, $\mathrm{Shorten}$ only, without ancilla extension), these codes strictly improve \textbf{1,450} minimum-distance lower bounds in Grassl's online reference database (\texttt{CodeTables.de}) as pure stabilizer codes, closing \textbf{16} entries to exact optimality ($d_{\mathrm{low}} = d_{\mathrm{up}}$). Appending terminal weight-$1$ stabilizer extension ($\mathrm{Extend}$) reaches $+204$ additional improved entries ($+2$ exact-optimal closures), for a total of \textbf{1,575} improved entries under single-operator propagation and \textbf{1,654} improved entries (\textbf{18} exact-optimal closures, including two new non-GRS Quantum MDS codes $[[11,1,6]]_5$ and self-dual $[[12,0,7]]_5$) under full purity-respecting transitive closure. Every parent code is accompanied by a cryptographic SHA-256 certificate and verified from first principles without symmetry assumptions via standalone clean-room verifiers in Python, multi-threaded Rust, and Magma.
\end{abstract}

\section{Introduction}

Let $\mathbb{F}_q$ denote the finite field with $q = p^e$ elements ($p$ prime). A $q$-ary quantum stabilizer code with parameters $[[n, k, d]]_q$ is a $q^k$-dimensional subspace of the $n$-qudit Hilbert space $(\mathbb{C}^q)^{\otimes n}$, specified as the joint eigenspace of an abelian subgroup of the $n$-qudit Pauli--Heisenberg--Weyl group, that detects arbitrary errors on up to $d - 1$ qudits and corrects arbitrary errors on up to $\lfloor (d - 1)/2 \rfloor$ qudits~\cite{Calderbank1998,Rains1999,Ashikhmin2001,Ketkar2006}. A central problem in quantum coding theory is to determine, for each alphabet $q$, block length $n$, and logical dimension $k$, the largest achievable minimum distance $d$; current lower and upper bounds are maintained by Grassl at \texttt{CodeTables.de}~\cite{Grassl2007} for $q = 2$ ($n \le 256$) and $q \in \{3, 4, 5, 7, 8, 9\}$ ($n \le 100$).

By the stabilizer formalism over finite fields~\cite{Ashikhmin2001,Ketkar2006}, any $\mathbb{F}_q$-linear $[2n, r_S]_q$ code $C_S \subseteq \mathbb{F}_q^{2n}$ ($r_S = n - k$) generated by $[X \mid Z] \in \mathbb{F}_q^{r_S \times 2n}$ that is self-orthogonal with respect to the $\mathbb{F}_q$-symplectic inner product,
\begin{equation}\label{eq:symp_ortho}
  X Z^\top - Z X^\top = \vb{0} \quad \text{over } \mathbb{F}_q,
\end{equation}
defines an $[[n, n - r_S, d]]_q$ stabilizer code~\cite[Lemma~16 \& Corollary~19]{Ketkar2006}. Moreover, the stabilizer code is \emph{pure} of minimum distance at least $d$ whenever every nonzero vector $(\vb{u}, \vb{v}) \in C_S^{\perp_s} \setminus \{\vb{0}\}$ has symplectic weight $\mathrm{wt}_s(\vb{u}, \vb{v}) = |\{j : (u_j, v_j) \ne (0, 0)\}| \ge d$. When $r_S = 2m$ is even, equipping $\mathbb{F}_{q^2}$ with the Frobenius involution $u \mapsto u^q$ and Hermitian inner product $\langle \vb{u}, \vb{v} \rangle_H = \sum_{j=0}^{n-1} u_j v_j^q$ yields the \emph{Hermitian construction}~\cite{Ashikhmin2001,Ketkar2006}: an $\mathbb{F}_{q^2}$-linear $[n, m]_{q^2}$ code $C$ with generator matrix $G \in \mathbb{F}_{q^2}^{m \times n}$ satisfying $G G^\dagger = \vb{0}$ and $d(C^{\perp_H}) \ge d$ defines a pure $[[n, n - 2m, \ge d]]_q$ stabilizer code.

In earlier releases of this study (\texttt{v1.0.0} and \texttt{v1.1.0}), $\lambda$-constacyclic and $1$-column bordered Hermitian codes yielded $18$ explicit pure stabilizer codes improving $29$ bounds in \texttt{CodeTables.de} (closing $5$ entries to $d_{\mathrm{low}} = d_{\mathrm{up}}$). Scaling to the entire parameter space exposed four structural barriers in standard algebraic searches:
\begin{enumerate}
  \item \emph{Residue-class gaps ($n \equiv 0, 1 \pmod m$):} Unbordered and $1$-bordered quasi-twisted (QT) codes miss all lengths $n = \ell m + b_p$ with $2 \le b_p \le m - 1$, whereas naive multi-column borders create low-weight ``comb'' codewords supported entirely inside the border.
  \item \emph{Even-parity lock ($n - k = 2m$):} $\mathbb{F}_{q^2}$-linear Hermitian codes force $r_S = n - k$ to be even, leaving odd-$r_S$ entries (such as $[[21,14,4]]_4$ at $r_S = 7$ or $[[46,11,13]]_8$ at $r_S = 35$) inaccessible to direct Hermitian constructions.
  \item \emph{Automorphism obstructions near the Quantum Singleton Bound ($n \le 15$):} Imposing cyclic, constacyclic, or monomial symmetries on short codes frequently forces $d(C^{\perp_H}) \le d^\star - 1$, blocking Quantum MDS (QMDS) parameters $n - k = 2d - 2$~\cite{Rains1999,Ball2021} beyond classical GRS lengths.
  \item \emph{Combinatorial syndrome blow-up at large distance ($d \in [10, 16]$):} Direct minimum-weight verification scales as $\binom{n}{d-1}$, becoming intractable for unstructured codes once $n \ge 50$ and $d \ge 11$.
\end{enumerate}

Section~\ref{sec:constructions} establishes four algebraic-geometric theorems overcoming each barrier in turn. Section~\ref{sec:results} presents all $18$ exact-optimal closures ($d_{\mathrm{low}} = d_{\mathrm{up}}$), complete generator matrices and $64$-character SHA-256 digests for all $15$ direct exact-optimal parent codes, and milestone high-distance records; Appendix~\ref{app:catalog} catalogs all $397$ pure parent certificates. Section~\ref{sec:verification} details the exact distinction between strictly pure propagation ($1{,}450$ cells) and terminal ancilla extension ($+204$ cells $= 1{,}654$ total), alongside our standalone clean-room verification suite.

\section{Algebraic and Geometric Constructions}\label{sec:constructions}

\subsection{Multi-Eigenmode Vandermonde Borders and Spectral Fourier Diagonalization}

Fix $m \ge 3$ and a norm-$1$ multiplier $\lambda \in \mathbb{F}_{q^2}^\times$ satisfying $\lambda^{q+1} = 1$, and set $R_{m,\lambda} = \mathbb{F}_{q^2}[x]/(x^m - \lambda)$. Each polynomial $a(x) = \sum_{t=0}^{m-1} a_t x^t \in R_{m,\lambda}$ defines the $\lambda$-constacyclic matrix $M_\lambda(a) \in \mathbb{F}_{q^2}^{m \times m}$ with $(r, c)$-entry $a_{r-c}$ for $r \ge c$ and $\lambda a_{m+r-c}$ for $r < c$. Under the conjugate-transpose involution $a^\dagger(x) = a_0^q + \lambda^{-1} \sum_{t=1}^{m-1} a_{m-t}^q x^t$ (note $\lambda^q = \lambda^{-1}$), we have $M_\lambda(a)^\dagger = M_\lambda(a^\dagger)$ and $M_\lambda(a) M_\lambda(b) = M_\lambda(ab \bmod (x^m - \lambda))$.

Suppose $\xi \in \mathbb{F}_{q^2}^\times$ is a norm-$1$ root of $x^m - \lambda = 0$ ($\xi^m = \lambda$ and $\xi^{q+1} = 1$, so $\xi^q = \xi^{-1}$), and define the eigenmode column $\vb{v}_*(\xi) = (1, \xi^{-1}, \xi^{-2}, \dots, \xi^{-(m-1)})^\top \in \mathbb{F}_{q^2}^m$. Direct multiplication gives $M_\lambda(x)\vb{v}_*(\xi) = \xi \vb{v}_*(\xi)$, whence $M_\lambda(a)\vb{v}_*(\xi) = a(\xi)\vb{v}_*(\xi)$ for all $a \in R_{m,\lambda}$.

\begin{theorem}[Comb-Free Multi-Eigenmode Vandermonde Quasi-Twisted Construction]\label{thm:vandermonde_qt}
Let $\lambda \in \mathbb{F}_{q^2}^\times$ satisfy $\lambda^{q+1} = 1$, let $\xi_1, \dots, \xi_{b_p} \in \mathbb{F}_{q^2}^\times$ ($0 \le b_p < m$) be distinct roots of $x^m - \lambda = 0$ of norm $\xi_s^{q+1} = 1$, and let $\beta_1, \dots, \beta_{b_p} \in \mathbb{F}_{q^2}^\times$. For $a_1(x), \dots, a_{\ell-1}(x) \in R_{m,\lambda}$, set $n = \ell m + b_p$ and
\[
  G = \bigl[\, I_m \;\big|\; M_\lambda(a_1) \;\big|\; \cdots \;\big|\; M_\lambda(a_{\ell-1}) \;\big|\; \beta_1 \vb{v}_*(\xi_1) \;\big|\; \cdots \;\big|\; \beta_{b_p} \vb{v}_*(\xi_{b_p}) \,\bigr] \in \mathbb{F}_{q^2}^{m \times n}.
\]
\begin{enumerate}
  \item $\mathrm{rank}_{\mathbb{F}_{q^2}}(G) = m$, the $b_p$ border columns are linearly independent over $\mathbb{F}_{q^2}$ (eliminating all pure-border dual codewords of weight $\le b_p$), and $G G^\dagger = \vb{0}$ if and only if
  \begin{equation}\label{eq:multi_border_poly}
    \sum_{i=1}^{\ell-1} a_i(x)\, a_i^\dagger(x) \equiv -1 - \sum_{s=1}^{b_p} \beta_s^{q+1} \sum_{t=0}^{m-1} \xi_s^{-t} x^t \pmod{x^m - \lambda}.
  \end{equation}
  \item Suppose further that $\gcd(m, p) = 1$ and $x^m - \lambda = \prod_{r=1}^m (x - \zeta_r)$ splits completely into $m$ norm-$1$ roots $\zeta_1, \dots, \zeta_m \in \mathbb{F}_{q^2}^\times$ (which holds whenever $m$ divides $q + 1$ and $\lambda^{(q+1)/m} = 1$). Then~\eqref{eq:multi_border_poly} is equivalent to the $m$ decoupled scalar norm equations in $\mathbb{F}_q$:
  \begin{equation}\label{eq:spectral_fourier}
    \sum_{i=1}^{\ell-1} \bigl(a_i(\zeta_r)\bigr)^{q+1} = -1 - m \sum_{s:\, \xi_s = \zeta_r} \beta_s^{q+1} \qquad (r = 1, \dots, m).
  \end{equation}
\end{enumerate}
\end{theorem}

\begin{proof}
Containing $I_m$ ensures $\mathrm{rank}(G) = m$. The $m \times b_p$ border block is a column-scaled Vandermonde matrix at the $b_p \le m$ distinct nonzero elements $\xi_1^{-1}, \dots, \xi_{b_p}^{-1}$; its leading $b_p \times b_p$ minor has determinant $\bigl(\prod_{s=1}^{b_p} \beta_s\bigr) \prod_{1 \le u < v \le b_p} (\xi_v^{-1} - \xi_u^{-1}) \ne 0$, so no nontrivial $\mathbb{F}_{q^2}$-linear combination of the $b_p$ border columns vanishes. Next, for $e_\xi(x) = \sum_{t=0}^{m-1} \xi^{-t} x^t \in R_{m,\lambda}$, the $(r, c)$-entry of $\vb{v}_*(\xi)\vb{v}_*(\xi)^\dagger$ is $\xi^{-r} (\xi^{-q})^c = \xi^{-(r-c)}$ since $\xi^q = \xi^{-1}$. For $r \ge c$, $\bigl[M_\lambda(e_\xi)\bigr]_{r,c} = \xi^{-(r-c)}$; for $r < c$, $\bigl[M_\lambda(e_\xi)\bigr]_{r,c} = \lambda \xi^{-(m+r-c)} = (\lambda \xi^{-m})\xi^{-(r-c)} = \xi^{-(r-c)}$. Thus $\vb{v}_*(\xi)\vb{v}_*(\xi)^\dagger = M_\lambda(e_\xi)$, so $G G^\dagger = M_\lambda\bigl(1 + \sum_{i=1}^{\ell-1} a_i a_i^\dagger + \sum_{s=1}^{b_p} \beta_s^{q+1} e_{\xi_s}\bigr) = \vb{0}$ iff~\eqref{eq:multi_border_poly} holds.

Under the hypotheses of~(2), the Chinese Remainder Theorem gives an $\mathbb{F}_{q^2}$-algebra isomorphism $R_{m,\lambda} \xrightarrow{\sim} \mathbb{F}_{q^2}^m$, $f \mapsto (f(\zeta_1), \dots, f(\zeta_m))$. Because $\lambda^{-1} \zeta_r^m = 1$ and $\zeta_r^{-1} = \zeta_r^q$, evaluating $a_i^\dagger$ at $\zeta_r$ yields $a_i^\dagger(\zeta_r) = a_{i,0}^q + \sum_{t=1}^{m-1} a_{i,m-t}^q \lambda^{-1} \zeta_r^t = \sum_{u=0}^{m-1} a_{i,u}^q \zeta_r^{-u} = (a_i(\zeta_r))^q$, hence $(a_i a_i^\dagger)(\zeta_r) = (a_i(\zeta_r))^{q+1}$. Finally, $e_{\xi_s}(\zeta_r) = \sum_{t=0}^{m-1} (\zeta_r / \xi_s)^t$ equals $m$ if $\xi_s = \zeta_r$ and $\frac{(\zeta_r/\xi_s)^m - 1}{\zeta_r/\xi_s - 1} = \frac{\lambda/\lambda - 1}{\zeta_r/\xi_s - 1} = 0$ otherwise, yielding~\eqref{eq:spectral_fourier}.
\end{proof}

Theorem~\ref{thm:vandermonde_qt} unlocks the entire Exact-Optimal family $[[23,13,5]]_4$, $[[24,14,5]]_4$, $[[25,15,5]]_4$, $[[26,16,5]]_4$, $[[27,17,5]]_4$, $[[28,18,5]]_4$, and $[[29,19,5]]_4$ over $\mathbb{F}_{16}$ ($m = 5$ dividing $4 + 1$, covering all residues $b_p \in \{0, 1, 2, 3, 4\}$), as well as $[[15,5,6]]_8$ over $\mathbb{F}_{64}$ ($m = 5, \ell = 3, \lambda = 6$).

\subsection{Equivariant \texorpdfstring{$\mathbb{F}_q$}{GF(q)}-Linear Symplectic Stabilizer Codes for Odd and Even \texorpdfstring{$r_S$}{r\_S}}

To construct codes with odd stabilizer rank $r_S = n - k$ (as well as $\mathbb{F}_q$-linear Lagrangian codes not induced from $\mathbb{F}_{q^2}$), we work directly in $\mathbb{F}_q^{2n}$~\cite{Ketkar2006}.

\begin{theorem}[Pure $\mathbb{F}_q$-Symplectic Rank Criterion]\label{thm:symplectic}
Let $q = p^e$, let $1 \le r_S < n$, and let $X, Z \in \mathbb{F}_q^{r_S \times n}$ satisfy $\mathrm{rank}_{\mathbb{F}_q}\!\bigl([\,X \;\big|\; Z\,]\bigr) = r_S$ and $X Z^\top - Z X^\top = \vb{0}$ over $\mathbb{F}_q$. If for every subset $S \subseteq \{0, \dots, n - 1\}$ of cardinality $|S| = d - 1$ the $r_S \times 2(d - 1)$ submatrix $[\,X_{\cdot, S} \;\big|\; Z_{\cdot, S}\,]$ has full $\mathbb{F}_q$-column rank $2(d - 1)$ (in particular requiring $r_S \ge 2d - 2$, the Quantum Singleton Bound), then $[\,X \;\big|\; Z\,]$ defines a pure $[[n, n - r_S, \ge d]]_q$ quantum stabilizer code.
\end{theorem}

\begin{proof}
Equip $\mathbb{F}_q$ with any $\mathbb{F}_p$-linear map $\mathrm{tr}: \mathbb{F}_q \to \mathbb{F}_p$ not identically zero (e.g.\ the field trace $\mathrm{Tr}_{\mathbb{F}_q/\mathbb{F}_p}$); then $(a, b) \mapsto \mathrm{tr}(ab)$ is a nondegenerate symmetric $\mathbb{F}_p$-bilinear form, and $\mathbb{F}_q$-linearity of $C_S = \mathrm{rowspace}_{\mathbb{F}_q}([X \mid Z])$ together with $X Z^\top - Z X^\top = \vb{0}$ implies trace-symplectic self-orthogonality $\mathrm{Tr}_{\mathbb{F}_q/\mathbb{F}_p}(\vb{x} \cdot \vb{z}'^\top - \vb{z} \cdot \vb{x}'^\top) = 0$ for all $(\vb{x}, \vb{z}), (\vb{x}', \vb{z}') \in C_S$~\cite[Lemma~16]{Ketkar2006}. A nonzero vector $(\vb{u}, \vb{v}) \in \mathbb{F}_q^{2n} \setminus \{\vb{0}\}$ supported on qudit subset $S$ with $|S| \le d - 1$ lies in $C_S^{\perp_s}$ iff $\sum_{c \in S} (u_c Z_{j,c} - v_c X_{j,c}) = 0$ for all $0 \le j < r_S$, which is a nontrivial $\mathbb{F}_q$-linear dependence among the $2|S|$ columns of $[\,X_{\cdot, S} \;\big|\; Z_{\cdot, S}\,]$. Full column rank $2(d - 1)$ on every $(d - 1)$-subset $S$ forbids all nonzero elements of $C_S^{\perp_s}$ of symplectic weight $\le d - 1$, establishing a pure $[[n, n - r_S, \ge d]]_q$ stabilizer code by~\cite[Corollary~19]{Ketkar2006}.
\end{proof}

Specializing $[X \mid Z]$ to $\ell$-quasi-cyclic and bordered Lagrangian block structures over $\mathbb{F}_q$ yields $31$ direct symplectic parent codes, including $20$ odd-$r_S$ codes such as the Exact-Optimal $[[21,14,4]]_4$ ($r_S = 7$, closing $3\text{--}4 \to 4$) and the high-distance record $[[46,11,13]]_8$ ($r_S = 35$, improving $12\text{--}18 \to 13\text{--}18$).

\subsection{Dieudonn\'e--Witt Unitary Householder Navigation on the Isotropic Grassmannian}

When $n \le 15$ and $2d = n - k + 2$ (QMDS) or $n - k + 1$, every nontrivial cyclic or monomial symmetry can obstruct the maximum minimum distance. Instead of imposing group symmetry, we navigate the full Hermitian isotropic Grassmannian
\[
  \mathrm{IGr}_H(m, n; \mathbb{F}_{q^2}) = \bigl\{ C \subseteq \mathbb{F}_{q^2}^n : \dim_{\mathbb{F}_{q^2}}(C) = m,\; C \subseteq C^{\perp_H} \bigr\}
\]
directly via rank-$1$ unitary reflections and transvections acting on the right of $G \in \mathbb{F}_{q^2}^{m \times n}$.

\begin{theorem}[Unitary Householder Reflections and Transvections over $\mathbb{F}_{q^2}$]\label{thm:householder}
Let $\vb{u} \in \mathbb{F}_{q^2}^n \setminus \{\vb{0}\}$, let $\nu = \vb{u}^\dagger \vb{u} = \sum_{j=0}^{n-1} u_j^{q+1} \in \mathbb{F}_q$, and let $\tau \in \mathbb{F}_{q^2}^\times$. Define $H(\vb{u}, \tau) = I_n - \tau \vb{u}\vb{u}^\dagger \in \mathbb{F}_{q^2}^{n \times n}$.
\begin{enumerate}
  \item $H(\vb{u}, \tau)$ is $\mathbb{F}_{q^2}$-unitary ($H H^\dagger = I_n$) if and only if
  \begin{equation}\label{eq:householder_cond}
    \tau + \tau^q = \nu\, \tau^{q+1} \quad \text{in } \mathbb{F}_q.
  \end{equation}
  By Hilbert's Theorem~90 and surjectivity of trace and norm on $\mathbb{F}_{q^2}/\mathbb{F}_q$, equation~\eqref{eq:householder_cond} has exactly $q$ nonzero solutions $\tau \in \mathbb{F}_{q^2}^\times$ when $\nu \ne 0$ (anisotropic reflections, satisfying $\tau^{-1} + \tau^{-q} = \nu$) and $q - 1$ nonzero solutions ($\tau + \tau^q = 0$, isotropic unitary transvections) when $\nu = 0$.
  \item For every $G \in \mathbb{F}_{q^2}^{m \times n}$ with $\mathrm{rank}(G) = m$ and $G G^\dagger = \vb{0}$, the $O(mn)$ rank-$1$ update $G' = G H(\vb{u}, \tau) = G - \tau (G\vb{u})\vb{u}^\dagger$ preserves $\mathrm{rank}(G') = m$ and $G'(G')^{\,\dagger} = \vb{0}$ identically, and by Witt's theorem~\cite{Dieudonne1963} the group generated by $\{H(\vb{u}, \tau)\}$ acts transitively on $\mathrm{IGr}_H(m, n; \mathbb{F}_{q^2})$.
\end{enumerate}
\end{theorem}

\begin{proof}
Expanding $H(\vb{u}, \tau) H(\vb{u}, \tau)^\dagger = (I_n - \tau \vb{u}\vb{u}^\dagger)(I_n - \tau^q \vb{u}\vb{u}^\dagger) = I_n - (\tau + \tau^q - \nu \tau^{q+1})\vb{u}\vb{u}^\dagger$ shows $H H^\dagger = I_n$ iff $\tau + \tau^q = \nu \tau^{q+1}$ because $\vb{u}\vb{u}^\dagger \ne \vb{0}$. Dividing by $\tau^{q+1} \ne 0$ when $\nu \ne 0$ gives $\mathrm{Tr}_{\mathbb{F}_{q^2}/\mathbb{F}_q}(\tau^{-1}) = \nu$, which has exactly $q$ solutions in $\mathbb{F}_{q^2}$ (none equal to $0$ since $\nu \ne 0$); when $\nu = 0$, $\mathrm{Tr}_{\mathbb{F}_{q^2}/\mathbb{F}_q}(\tau) = 0$ has $q - 1$ nonzero solutions. Unitarity gives $G'(G')^{\,\dagger} = G H H^\dagger G^\dagger = G G^\dagger = \vb{0}$ and $\mathrm{rank}(G') = \mathrm{rank}(G) = m$. By Witt's extension theorem for nondegenerate Hermitian spaces over $\mathbb{F}_{q^2}$~\cite{Dieudonne1963}, the unitary group $U_n(\mathbb{F}_{q^2})$ acts transitively on $m$-dimensional totally isotropic subspaces and is generated by unitary reflections and transvections of the form $H(\vb{u}, \tau)$ (with the sole known classical exception $(q, n) = (2, 4)$ not needed for $n \ge 11$).
\end{proof}

Executing massive warp-parallel Tabu/WalkSAT trajectories via sparse rank-$1$ Householder steps (weight-$2$, $3$, and $4$ vectors $\vb{u}$) with zero group-symmetry constraints resolved four longstanding open short-length bounds: $[[13,1,6]]_3$, $[[11,3,5]]_4$ (inducing $[[11,2,5]]_4$ and $[[12,3,5]]_4$), and the two non-GRS QMDS codes $[[11,1,6]]_5$ and $[[12,0,7]]_5$ ($2d = n - k + 2$, exceeding the classical $\mathbb{F}_5$-MDS length $q + 1 = 6$~\cite{Ball2021}).

\subsection{Two-Block and Three-Block NSC Quasi-Unitary Matrix-Product Codes}

To reach pure minimum distances $d \in [10, 16]$ at block lengths up to $n = 100$ without $\binom{100}{15}$ brute-force search, we construct $2$-block and $3$-block upper-triangular matrix-product codes~\cite{Blackmore2001,Hernando2009} with Frobenius-twisted column scalings over $\mathbb{F}_{q^2}$. For a vector $\vb{x} = (x_0, \dots, x_{n_0-1}) \in \mathbb{F}_{q^2}^{n_0}$, denote its componentwise Frobenius conjugate by $\vb{x}^{[q]} = (x_0^q, \dots, x_{n_0-1}^q)$ and coordinatewise product by $\odot$.

\begin{theorem}[2-Block and 3-Block NSC Quasi-Unitary Matrix-Product Hermitian Codes]\label{thm:mp23}
Let $n_0 \ge 4$ and let $C_s = \mathrm{rowspace}_{\mathbb{F}_{q^2}}(G_s)$ ($G_s \in \mathbb{F}_{q^2}^{m_s \times n_0}$ of full rank $m_s$) be linear codes over $\mathbb{F}_{q^2}$.
\begin{enumerate}
  \item \emph{(2-Block Construction, $n = 2n_0$, $m = m_1 + m_2$):} Let $\vb{D} = (D_0, \dots, D_{n_0-1}) \in (\mathbb{F}_{q^2}^\times)^{n_0}$ have all entries nonzero, and set
  \[
    G = \begin{bmatrix} G_1 & G_1 \operatorname{diag}(\vb{D}) \\ \vb{0} & G_2 \end{bmatrix} \in \mathbb{F}_{q^2}^{(m_1 + m_2) \times (2n_0)}.
  \]
  If $G G^\dagger = \vb{0}$ over $\mathbb{F}_{q^2}$, then $C = \mathrm{rowspace}(G)$ has dimension $m_1 + m_2$, satisfies $C \subseteq C^{\perp_H}$, and has dual minimum distance
  \begin{equation}\label{eq:mp2_dist}
    d(C^{\perp_H}) \ge \min\!\bigl(d(C_1^{\perp_H}),\; 2\, d(C_2^{\perp_H})\bigr),
  \end{equation}
  yielding a pure $[[2n_0,\, 2n_0 - 2(m_1 + m_2),\, \ge \min(d(C_1^{\perp_H}), 2d(C_2^{\perp_H}))]]_q$ stabilizer code.
  \item \emph{(3-Block NSC Construction, $n = 3n_0$, $m = m_1 + m_2 + m_3$):} Let $\vb{D}_1, \vb{D}_2, \vb{E} \in (\mathbb{F}_{q^2}^\times)^{n_0}$ satisfy the Non-Singular-by-Columns (NSC) condition $D_{1,j} E_j \ne D_{2,j}$ for every $0 \le j < n_0$, and set
  \[
    G = \begin{bmatrix}
      G_1 & G_1 \operatorname{diag}(\vb{D}_1) & G_1 \operatorname{diag}(\vb{D}_2) \\
      \vb{0} & G_2 & G_2 \operatorname{diag}(\vb{E}) \\
      \vb{0} & \vb{0} & G_3
    \end{bmatrix} \in \mathbb{F}_{q^2}^{(m_1 + m_2 + m_3) \times (3n_0)}.
  \]
  If $G G^\dagger = \vb{0}$ over $\mathbb{F}_{q^2}$, then $\dim(C) = m_1 + m_2 + m_3$, $C \subseteq C^{\perp_H}$, and
  \begin{equation}\label{eq:mp3_dist}
    d(C^{\perp_H}) \ge \min\!\bigl(d(C_1^{\perp_H}),\; 2\, d(C_2^{\perp_H}),\; 3\, d(C_3^{\perp_H})\bigr).
  \end{equation}
\end{enumerate}
\end{theorem}

\begin{proof}
Block upper-triangularity with full-rank diagonal blocks $G_s$ gives $\mathrm{rank}(G) = \sum_s m_s$. For~(1), let $(\vb{u}, \vb{v}) \in C^{\perp_H} \setminus \{\vb{0}\}$ ($\vb{u}, \vb{v} \in \mathbb{F}_{q^2}^{n_0}$). The condition $G (\vb{u}, \vb{v})^\dagger = \vb{0}$ reads $G_1(\vb{u} + \vb{D}^{[q]} \odot \vb{v})^\dagger = \vb{0}$ and $G_2 \vb{v}^\dagger = \vb{0}$. Set $\vb{w}_1 = \vb{u} + \vb{D}^{[q]} \odot \vb{v} \in C_1^{\perp_H}$ and $\vb{w}_2 = \vb{v} \in C_2^{\perp_H}$. If $\vb{w}_1 \ne \vb{0}$, subadditivity of Hamming weight on each coordinate $j$ gives $\mathrm{wt}(\vb{u}) + \mathrm{wt}(\vb{v}) \ge \mathrm{wt}(\vb{w}_1) \ge d(C_1^{\perp_H})$. If $\vb{w}_1 = \vb{0}$, then $\vb{v} \ne \vb{0}$ and $u_j = -D_j^q v_j$ has the exact same support as $v_j$ because $D_j \ne 0$, whence $\mathrm{wt}(\vb{u}, \vb{v}) = 2\,\mathrm{wt}(\vb{v}) \ge 2\,d(C_2^{\perp_H})$, proving~\eqref{eq:mp2_dist}.

For~(2), let $(\vb{u}_1, \vb{u}_2, \vb{u}_3) \in C^{\perp_H} \setminus \{\vb{0}\}$. Then $\vb{w}_1 := \vb{u}_1 + \vb{D}_1^{[q]} \odot \vb{u}_2 + \vb{D}_2^{[q]} \odot \vb{u}_3 \in C_1^{\perp_H}$, $\vb{w}_2 := \vb{u}_2 + \vb{E}^{[q]} \odot \vb{u}_3 \in C_2^{\perp_H}$, and $\vb{w}_3 := \vb{u}_3 \in C_3^{\perp_H}$.
\emph{Case~1 ($\vb{w}_1 \ne \vb{0}$):} $\sum_{s=1}^3 \mathrm{wt}(\vb{u}_s) \ge \mathrm{wt}(\vb{w}_1) \ge d(C_1^{\perp_H})$.
\emph{Case~2 ($\vb{w}_1 = \vb{0}, \vb{w}_2 \ne \vb{0}$):} For every $j \in \mathrm{supp}(\vb{w}_2)$, $(u_{2,j}, u_{3,j}) \ne (0, 0)$. If $u_{3,j} = 0$, then $u_{2,j} = w_{2,j} \ne 0$ and $u_{1,j} = -D_{1,j}^q u_{2,j} \ne 0$ ($D_{1,j} \ne 0$); if $u_{3,j} \ne 0$, at least one of $u_{2,j}$ or $u_{1,j} = -D_{1,j}^q u_{2,j} - D_{2,j}^q u_{3,j}$ is also nonzero whenever $u_{2,j} = 0$ ($D_{2,j} \ne 0$), so in every subcase at least two of $(u_{1,j}, u_{2,j}, u_{3,j})$ are nonzero on $\mathrm{supp}(\vb{w}_2)$, giving $\sum_{s=1}^3 \mathrm{wt}(\vb{u}_s) \ge 2\,\mathrm{wt}(\vb{w}_2) \ge 2\,d(C_2^{\perp_H})$.
\emph{Case~3 ($\vb{w}_1 = \vb{w}_2 = \vb{0}, \vb{w}_3 \ne \vb{0}$):} Then $u_{2,j} = -E_j^q u_{3,j}$ and $u_{1,j} = (D_{1,j} E_j - D_{2,j})^q u_{3,j}$. Since $E_j \ne 0$ and $D_{1,j} E_j \ne D_{2,j}$ for all $j$, all three of $(u_{1,j}, u_{2,j}, u_{3,j})$ are nonzero for every $j \in \mathrm{supp}(\vb{w}_3)$, so $\sum_{s=1}^3 \mathrm{wt}(\vb{u}_s) = 3\,\mathrm{wt}(\vb{w}_3) \ge 3\,d(C_3^{\perp_H})$, establishing~\eqref{eq:mp3_dist}.
\end{proof}

By choosing $C_1$ as an $[n_0, m_1]_{q^2}$ projective generalized Reed--Solomon (PGRS) MDS code ($n_0 \le q^2 + 1$, $d(C_1^{\perp_H}) = m_1 + 1$) and $C_2$ via Frobenius-conjugated PGRS monomials satisfying $G_1 \operatorname{diag}(\vb{1} + \vb{D}\odot\vb{D}^{[q]}) G_1^\dagger = \vb{0}$, $G_1 \operatorname{diag}(\vb{D}) G_2^\dagger = \vb{0}$, and $G_2 G_2^\dagger = \vb{0}$, Theorem~\ref{thm:mp23} produces $287$ explicit pure parent codes ($285$ MP2 and $2$ MP3) reaching $d = 16$ at $n = 100$ over $q \in \{7, 8\}$ and achieving 116 direct $\Delta d = +2$ jumps over \texttt{CodeTables.de}.

\section{Purity-Preserving Propagation and Clean-Room Verification}\label{sec:verification}

\subsection{Two-Tier Accounting: Strictly Pure Closure vs.\ Terminal Extension}

From each verified \emph{pure} $[[n, k, d]]_q$ parent stabilizer code ($d \ge 3$), standard quantum propagation operators~\cite[Theorem~6]{Calderbank1998} and~\cite[Lemmas~69--72]{Ketkar2006} fall into two distinct purity classes:
\begin{enumerate}\small
  \item \textbf{Purity-Preserving Operators ($\mathrm{PureSubcode}$, $\mathrm{Puncture}$, $\mathrm{Shorten}$):}
  \begin{itemize}
    \item $\mathrm{PureSubcode}$ ($1 \le s \le k$): Promoting $s$ independent pure logical operators into the stabilizer yields a \emph{pure} $[[n, k - s, \ge d]]_q$ code.
    \item $\mathrm{Puncture}$ ($1 \le s \le d - 2$, $n - s \ge \max(1, k)$): Puncturing $s$ qudits of a pure $[[n, k, d]]_q$ code yields a \emph{pure} $[[n - s, k, \ge d - s]]_q$ code.
    \item $\mathrm{Shorten}$ ($1 \le s \le d - 2$, $n - s \ge k + s$): Shortening $s$ qudits of a pure $[[n, k, d]]_q$ code yields a \emph{pure} $[[n - s, k + s, \ge d - s]]_q$ code.
  \end{itemize}
  \item \textbf{Impure Terminal Ancilla Extension ($\mathrm{Extend}$):} Appending $s \ge 1$ ancilla qudits stabilized by $Z^{\otimes s}$ yields a valid $[[n + s, k, \ge d]]_q$ stabilizer code containing weight-1 stabilizers (hence impure whenever $d \ge 2$).
\end{enumerate}
Because PureSubcode requires purity ($d(C_S) \ge d$) whereas Extend introduces weight-1 stabilizers, PureSubcode (and likewise Puncture and Shorten) must \emph{never} be applied after Extend. Accordingly, both \texttt{CODETABLES\_\allowbreak V1\_\allowbreak 2\_\allowbreak IMPACT\_\allowbreak REPORT.json} and \texttt{verify\_all\_qecc.py} audit two separate closure tiers:
\begin{itemize}\small
  \item \textbf{Tier~1 --- Strictly Pure Closure (`Pure Closure'):} Iterating only $\{\mathrm{PureSubcode},\allowbreak \mathrm{Puncture},\allowbreak \mathrm{Shorten}\}$ on the $397$ pure parents until convergence strictly improves \textbf{1,450} entries in \texttt{CodeTables.de} as \emph{pure} stabilizer codes and closes \textbf{16} entries to exact optimality.
